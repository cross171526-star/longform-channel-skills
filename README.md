## 내려받고 설치

이 저장소의 **Code → Download ZIP**으로 전체를 내려받아 압축을 풉니다. 그 안에서:

```bash
python3 restore-package.py
cd longform-channel-skills
python3 lfc.py install
```

첫 명령은 코드 ZIP과 `longform-assets-*.zip`을 한 폴더로 복원하며 각 ZIP과 복원 파일의 SHA256을 검사합니다. GitHub 웹 업로드 한도 때문에 자산을 분리했으므로 **모든 ZIP과 package-parts.json을 같은 폴더에** 두세요. 기존 출력 폴더가 있으면 덮어쓰지 않습니다. 설치도 기존 동명 스킬의 변경을 덮어쓰지 않습니다.

기존 `longform-channel-skills.zip` 파일명은 유지하며 최신 코드·규칙이 담겨 있습니다. 서체·이미지·효과음은 이번에 추가한 자산 ZIP을 반드시 함께 복원합니다. 기존 `longform-project-handoff.zip`도 갱신했으며 이제 통합본에도 같은 스킬이 포함됩니다.

## 들어 있는 파일

복원된 패키지의 `skills/`에 공통 클로너·분석·기획·제작·피드백, 운영 연결, 새 프로젝트 인계, 4개 채널, 공통 쇼츠, 과거 스포츠 쇼츠 참고, 영상 읽기, 결과물 정리 스킬을 제공합니다. `examples/`에는 실제 승인 본편의 렌더 구현 참고, `release/`에는 원본·배포 해시와 검증 기록이 있습니다. 전체 소스는 ZIP 내부에서 확인하고 수정할 수 있습니다.

Python 3.12 이상·Node 22 이상·ffmpeg와 본인 TTS/API 접근을 준비하세요. 이미지 생성 도구, 새 주제의 원자료·음악·음성은 별도 입력입니다. 기준에 필요한 고정 자산과 예제는 동봉하며 서체 라이선스·효과음 크레딧을 유지합니다. 실행 환경 준비는 복원된 패키지의 README를 따릅니다.

검증: 스킬 15종, Python 문법 114개, 설치·인계·출력 동작 5개 테스트, 쇼츠 42프레임 픽셀 일치, 별별역사 9개 예제·43개 고정 자산 검사 통과. 새 컴퓨터 전체 설치·유료 TTS·새 본편 전체 렌더는 미수행입니다.
